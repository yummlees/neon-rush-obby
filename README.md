# Neon Rush Obby

A free neon parkour game for a phone or computer browser. Ten stages, checkpoints, jump pads, and a best-time saved on this device. No login. No payments.

## Play

Open the site and tap **Play**. That is the whole setup.

## Controls

- **Move:** A / D, arrow keys, or the on-screen arrows
- **Jump:** Space, W, up arrow, or the Jump button
- **Pause:** P or Escape
- Land on **cyan pads** to bounce higher
- **Moving bars** carry you if you stand on them
- **Spikes** and **lava** send you back to the last stage start
- Crumble platforms shake, then drop — keep moving

## Best time

Your fastest finish is stored in this browser only (localStorage). Clearing site data clears it. Friends each have their own time on their own phone.
